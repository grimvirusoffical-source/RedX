RedX (unsigned build)

1. Drag RedX to Applications.
2. The first time: right-click (or Control-click) RedX in Applications, choose Open, then Open again.
   macOS shows "unidentified developer" because this build is not signed with a paid Apple Developer ID
   or notarized. If macOS blocks it anyway: System Settings > Privacy & Security > "Open Anyway".
3. RedX starts its host in the background and opens the console in your browser.
   The first time, the console shows your admin key ONCE. Copy it somewhere safe.
Stop RedX: Activity Monitor > redxd > Quit.  Your data is in ~/Library/Application Support/RedX
